1. Create client ID and private repository from the template.
2. Complete manifest, ownership, services, dashboard reference and Drive reference.
3. Create Google Shared Drive and password-manager collection.
4. Connect evidence sources only after access classification.
5. Capture company, people, operations, offer, ICP, positioning, beliefs, history, mistakes and five-year ambition.
